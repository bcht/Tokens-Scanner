# Tokens Scanner

统计本机四类 agent 工具的 token 消耗。左侧是类似 GitHub 贡献图的热力图,
右侧是可切换的数字统计。颜色按顺序色阶表示量级,不是分类配色。

> **本项目由 AI 编写。**
> 代码、界面、文档全部出自 **Claude**(Anthropic),经由 Claude Code 完成;
> 人类负责提需求、做决策和验收,没有手写代码。
> 如果你是来评估代码质量的:请把它当作 AI 生成的产物来看待,而不是人类的手笔。

## 界面语言

右上角可以切中文 / English。选择**存在存档里**,下次启动还是它。

英文只做**排版层面**的适配,不动布局:

- 文案层面就挑的短词(`Split` / `Source` / `Model` / `Scale`,而不是
  `Breakdown` / `By source` / ...)——现有的横排选择器和行标签是按中文宽度排的,
  英文太长会撑行,那就成改布局了
- 字体栈去掉中文回退;中文加一点正字距换呼吸,英文收回 0
- 日期、数字、来源名(Claude Code 等专有名词)两种语言共用
- 热力图的月份名(Jan–Dec)和星期标记(M/W/F)跟着切换

## 运行

```bash
python main.py
```

需要 Python 3.14+(解压 DSH 会话用到标准库 `compression.zstd`,该模块从 3.14 起提供;
更早的版本要 `pip install zstandard`,`scanner.py` 里有回退分支)。

## 日志

**默认就写**,不用加参数。文件在 exe 旁边(目录不可写时退到 `%LOCALAPPDATA%\TokenUsage\`):

```
tokens-scanner.log        最新日志,写入中
tokens-scanner.log.1      上一份(超过 2 MB 时轮转)
```

为什么默认就写:打包成 windowed 的 exe 没有控制台,启动失败时表现是
**「双击没反应」**——没日志就等于什么都没留下,只能靠猜。日志里同时会收进
pywebview 自己的消息(比如端口被占用),那类问题以前是完全看不见的。

启动失败时**还会弹一个对话框**,告诉你错在哪、日志在哪个文件。

### `--debug`

```bash
Tokens-Scanner.exe --debug
```

把级别降到 DEBUG:逐个会话文件(路径、记录条数、单文件耗时)、每次 JS 取数、
pywebview 的内部日志全部记下来。并且在有控制台时**同步打印到控制台**。

不加参数时只记 INFO:启动信息、扫描汇总、错误与未捕获异常。

> 日志和存档一样含**本机绝对路径**,已在 `.gitignore` 里排除,不会被提交。

## 打包成 exe

双击 `build.bat`,产物在 `dist\Tokens-Scanner.exe`。脚本会先删掉 `ui\data.json`
再打包 —— 那是浏览器调试用的缓存,打进正式包的话,桥接一旦失败程序会拿
构建那一刻的旧数据冒充当前数据。

## 数据库

`usage-cache.db` 和 exe 放在同一目录,启动时先读它。

会话文件会长到几百兆,全量解析一次要几秒;而自动刷新每分钟都跑一遍。
所以是**按文件增量**的:只有真正变过的文件才重新解析,没变过的直接用存档结果。

量级参考(会话文件几十到上百个):

| | 耗时 |
| --- | --- |
| 冷启动(全部新解析) | 约 2–3 s |
| 热启动(全部读存档) | **几十 ms** |

**它是存档,不是纯缓存 —— 磁盘上已经消失的会话文件,记录仍然留着。**
清理掉旧会话之后,那些天的用量不会从图上凭空消失。实测:两个会话(合计 302)
在「删掉一个文件」「把另一个搬到别的项目目录」「两个都删光」之后,总量始终是 302。

主键用的是**会话标识**而不是路径,所以文件被挪了位置、改了目录名也仍认得出是同一个会话,
不会因为路径变了就多出一条记录、把用量算两遍。

`cache.py` 里的 `CACHE_VERSION` 一旦变动,会走一套**保护性的重建流程**,
而不是把旧数据一扔了事:

1. 用 `VACUUM INTO` 把旧库**整体另存**为 `usage-cache.<旧版本号>.db`(兜底,人工可恢复)
2. 把旧表改名为 `file_cache_prev`,建新表,**尽量把还能按当前格式读出来的记录搬过来**
3. 搬不动的(记录格式确实变了)就跳过 —— 它们在另存的那份备份里还完整躺着

实测:记录格式兼容时升级后总量从 101 → **101**,数字无感;不兼容时归 0,
但备份文件存在且内容完整。升级发生时界面会在右侧提示,并说明另存到了哪个文件。

为什么不直接 DROP 表:磁盘上已经没有的会话,记录只存在于库里,丢了就找不回来。
为什么不只 DELETE 行:列本身也可能变了,而 `CREATE TABLE IF NOT EXISTS`
不会改动已存在的表 —— 写入会因列对不上而静默失败,存档表面正常实际全废。

连接用 `check_same_thread=False` 并配一把自己的锁:pywebview 会在**不同的工作线程**
上调用 JS API,而 sqlite3 默认禁止连接跨线程使用。这个坑很隐蔽 —— 首次加载通常成功
(建了库),之后某次轮询落到别的线程就报错,存档开始静默失效,界面显示「数据库不可用」。

程序目录不可写时(比如装在 `Program Files`),库会退到
`%LOCALAPPDATA%\TokenUsage\`,界面上会说明。

## 界面

**界面**

左侧是一张**固定画最近 365 天**的热力图。它不受时间范围影响,只受「数据来源」影响 ——
取消勾选某个来源,对应的格子就灭掉。点格子有悬浮明细,点「表格」看逐日清单
(热力图颜色的等价读法)。

**颜色分档用对数刻度**,不是分位数。分位数等于按**排名**上色:实测中 52.9M 和 146.8M
(差 2.8 倍)会被划成同一档,而 48.3M 和 51.3M(差 6%)却能差两档 —— 颜色反映的是序数
而不是用量。改成在 log 空间里等分之后,相近的量级才真的拿到相近的颜色。
鼠标悬停到图例的色块上会显示该档对应的实际区间(如 `14.41M – 31.37M`)。

标题旁的**快捷区间**(近 7 天 / 近 30 天 / 近一年 / 全部)和**起止日期输入框**
控制的是右侧数字,不是上面这张热力图 —— 这是个容易误解的地方,特意写在这里。

右侧数字:

- **数据来源**:单选,`全部来源` 或某一具体来源。选中哪个,顶部的 LOGO 就换成哪个。
  换来源时**不做滑动动画**,直接换 —— 只有切分组才滑
- **合计大数字**:橙色,后面跟着 `tokens`,统计范围就是左侧的时间范围。
  它带滚动动画:位数变化(进位/退位)时 **数字和 `tokens` 一起平滑平移**
  (按右对齐补位,再把补偿位移施加在两者的共同祖先上),不是瞬移;
  9 进位到 0 走轨道上重复的那个 0,所以是向前的正确方向
- **构成 / 按来源 / 按模型 / 规模**:单选,一次只看一组。切换分组时整块**横向推走**,
  方向跟着选项的左右位置走 —— 点到左边的选项内容往右滑,点到右边的往左滑,
  和选择器的空间关系对得上;**这些明细数字不做滚动动画,直接改值**
  - 「规模」一栏里的**连续活跃天数**:从时间范围的**结束日**(最新那天)往前倒推,
    连着数到第一个没用量的日子为止;结束日当天没用量就是 0。
    注意三个快捷区间的结束日都是今天,所以它们的值通常一样;
    想看更长的连续,把结束日往前调(比如调到某个连续使用的最后一天)
- **按模型不折叠**,有多少列多少;模型名全部来自数据,代码里没有写死任何一个
- **自动刷新**在右下角:30 秒 / 1 分 / 5 分 / 关,默认 1 分。窗口最小化时不扫,
  切回来立刻补一次
- 所有没探测到的来源都会逐个在下方声明,不是只提某一个

所有选中态一律是**墨色描边**,不用墨色填充 —— 大黑块太沉。

**其它**
- 自动刷新在右下角:30 秒 / 1 分 / 5 分 / 关,默认 1 分。
  窗口最小化时不扫,切回来立刻补一次
- 所有没探测到的来源都会逐个在下方声明,不是只提某一个
- 「表格」按钮给出逐日明细,也是热力图颜色的等价读法

## 口径

- **合计 = 输入 + 输出 + 缓存读 + 缓存写。** 缓存读通常占九成以上,
  所以「构成」一栏把它拆开列出来,方便看真实构成。
- Claude 的同一条 assistant 消息会被重复写入多个文件且内容完全一致,
  按 `message.id` 全局去重,否则用量翻倍。
- 热力图颜色分档用当前区间的分位数切五级。

## 配色与字体

中性色取自「陶纸主义」规范:纸底 `#F4F1EA`(刻意避开纯白)、浮层 `#FBF9F4`、
沉积 `#EDE8DC`、墨 `#1E1B17`、细线 `#E0DACB`。

强调色 `#D97757` **只出现在两处** —— 热力图格子、合计大数字。
按钮、选择器、分段控件一律墨色细线,不用橙色填充。

热力图五级 `#F5BDAA → #E99375 → #D16E4B → #AA5435 → #7F3F28`,
明度等距(OKLCH 每级 ΔL=0.100);空格 `#E5DFD6`,比纸底低 0.054。

一级色刻意压到 L 0.845:更早那版一级色是 L 0.905,和纸底几乎分不开 ——
范围一短(比如只看 9 天),整张图看起来就像没画出来。空格的明度也只能动一点点,
再深整年图就发脏,所以拉开一二级之间靠的是**彩度**而不是明度。

字体全部用系统自带的无衬线,不引入任何在线字体 ——
规范里的 Newsreader / Inter / IBM Plex Mono 需要联网下载,离线 exe 用不了。

LOGO 取自 `ui/logos/`,由使用者提供;「全部来源」用的是本应用自己的标记。
